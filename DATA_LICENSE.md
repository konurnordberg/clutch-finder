# Dataset attribution

The included Chroma database contains transformed NFL play-by-play descriptions and metadata from nflverse/nflverse-data:
https://github.com/nflverse/nflverse-data

Source license: Creative Commons Attribution 4.0 International (CC BY 4.0):
https://creativecommons.org/licenses/by/4.0/
Source license file: https://github.com/nflverse/nflverse-data/blob/main/LICENSE.md

Changes: selected postseason records, removed records without a possession team or description and no-play events, added game context, grouped adjacent descriptions, split long passages, and computed vector embeddings. Original source descriptions are retained in metadata. The build manifest identifies the download and checksum.
